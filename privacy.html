Privacy Policy

Deal Flow Radar · last updated September 28, 2026

Deal Flow Radar is a personal application used only by its owner, who runs it on their own computer. This policy explains how it handles data from the owner's Google account.

Data accessed

With the Gmail read-only permission (gmail.readonly), Deal Flow Radar reads the email messages in a single Gmail label chosen by the owner, which holds alert emails from business marketplaces. It reads each message's sender, subject, date and body. It does not read messages outside that label, and it never sends, deletes or changes email.

How the data is used

Messages are used only to produce the owner's weekly research report: identifying listings of businesses for sale, extracting their stated facts (such as revenue, profit and asking price), grouping them into product niches and scoring them. The data is not used for advertising, is not sold, and is not used to train AI models.

Storage

Messages and the facts extracted from them are stored in a database on the owner's own computer. The Google sign-in token is stored in a file on that computer that only the owner's account can read. Nothing is stored on a server operated by Deal Flow Radar; there is none.

Sharing

To extract facts from each message, the message text is sent to the Anthropic Claude API, which processes it and returns the extracted facts. Anthropic acts as a service provider for this purpose. Google user data is not shared with anyone else and is not transferred for any other purpose.

Limited Use

Deal Flow Radar's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept on the owner's computer until the owner deletes it. Access can be withdrawn at any time at myaccount.google.com/permissions; deleting the local database and token file removes all stored data.
